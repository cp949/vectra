# 도메인 문서 사용 규칙

이 저장소는 pnpm + Turborepo 모노레포이지만 단일 컨텍스트다. 업무 용어는 루트에 두고, 결정은 `docs/internal/adr/`에 둔다.

## 탐색 전에 읽을 문서

- 루트 `CONTEXT.md`: 업무 용어집.
- `docs/internal/adr/`: 작업 영역에 관련된 결정.

`CONTEXT.md`가 없으면 조용히 진행한다. 없다는 사실을 알리거나 미리 만들자고 제안하지 않는다. 용어가 실제로 확정될 때 `domain-modeling` 스킬이 만든다.

## 파일 구조

```
/
├── CONTEXT.md
├── docs/internal/adr/
├── sub/vectra/
└── apps/
```

- ADR 파일명은 `NNNN-이름.md`다. 번호는 기존 최대값 + 1이다.
- ADR 첫 제목은 `# ADR NNNN: 제목`, 그다음 줄은 `상태: 승인` 형식이다.

## 용어집 어휘 사용

이슈 제목, 리팩터링 제안, 가설, 테스트 이름에 업무 개념을 쓸 때는 `CONTEXT.md`에 정의된 용어를 쓴다. 용어집이 피하라고 한 동의어로 바꾸지 않는다. 필요한 개념이 용어집에 없으면 새 용어를 만들고 있는지, 용어집에 빈 곳이 있는지 판단한다. 빈 곳이면 `domain-modeling`으로 넘긴다.

## ADR 충돌 표시

출력이 기존 ADR과 어긋나면 조용히 덮어쓰지 말고 명시한다.

> ADR 0006(...)과 충돌한다. 다시 검토할 만한 이유는 ...
