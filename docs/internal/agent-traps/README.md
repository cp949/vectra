# Agent 함정 라이브러리

이 폴더는 여러 작업에서 반복될 가능성이 높은 에이전트 실수와 방지책을 정리한다.

계획 단계에서는 작업 폴더의 `함정.md`를 미리 만들지 않는다. 작업 중 새 함정이 실제로
발견되었을 때만 해당 작업 폴더의 `함정.md`를 생성하거나 append한다. 작업 완료 시 반복
가능성이나 영향도가 높다고 판단한 항목만 이 폴더로 승격한다.

## 사용 원칙

- 모든 함정을 매번 읽지 않는다.
- 계획서나 TASK 문서의 `확인할 함정` 섹션에 연결된 항목만 작업 시작 전에 확인한다.
- 이미 `AGENTS.md`, `CLAUDE.md`, `_works/README.md`, 체크리스트에 충분히 있는 일반 규칙은
  중복하지 않는다.
- 함정 문서는 실제 증상과 방지 방법이 함께 있을 때만 추가한다.

## 승격 기준

다음 중 하나라도 해당하면 `docs/internal/agent-traps/` 승격을 검토한다.

- 같은 실수가 두 번 이상 반복될 가능성이 높다.
- public API, package surface, export 경계를 깨뜨릴 수 있다.
- typecheck, test, build, release 준비에서 반복 비용을 만들 수 있다.
- 큰 reference source 분석처럼 작업 비용이 큰 영역에서 방향을 잃게 만들 수 있다.
- 다음 작업자가 이 함정을 몰라도 될 만큼 명확히 문서화할 가치가 있다.

## 작성 형식

함정 문서는 짧게 유지한다.

```md
# <함정 이름>

태그: `<tag>`, `<tag>`

## 함정

## 증상

## 방지

## 관련 작업
```
